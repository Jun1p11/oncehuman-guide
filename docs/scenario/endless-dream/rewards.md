# 클리어 보상 표

!!! info "키워드 표기"
    - **키워드 포함**: 키워드 모듈과 비키워드 모듈이 모두 나올 수 있음
    - **키워드만**: 키워드 모듈만 나옴
    - **비키워드만**: 비키워드 모듈만 나옴

| 콘텐츠 | 활성화 비용 | 주요 보상 |
|--------|-------------|-----------|
| **망각** | – | 무기 모듈 상자 <span class="oh-badge oh-badge--sheet">키워드 포함</span><br>스타더스트 에테르<br>에너지 링크<br>무기 튜닝 설계도 |
| **만하임** | – | 방어구 모듈 선택 상자 <span class="oh-badge oh-badge--sheet">키워드 포함</span><br>나비의 꿈 |
| **[얕은 잠](shallow-sleep.md)** | [자각의 모래](index.md#자각의-모래-얻는-법) 50 | 현실 조각<br>방어구 모듈 선택 상자<br>에너지 링크 |
| **[깊은 잠](deep-sleep.md)** | [자각의 모래](index.md#자각의-모래-얻는-법) 100 | 현실 조각<br>무기 모듈 상자 <span class="oh-badge oh-badge--guide">비키워드만</span><br>에너지 링크<br>무기 튜닝 설계도 |
| **[영면자 (킨)](kin.md)** | [자각의 모래](index.md#자각의-모래-얻는-법) 1000 (잔영 2000) | 현실 조각 **없음**<br>현실 조각을 **써서** 추가 보상: 무기 · 마스크 모듈 상자 <span class="oh-badge oh-badge--sheet">키워드만</span> |
| **[실버게이트 (다키니)](silvergate.md)** | – | 무기 · 마스크 모듈 상자 <span class="oh-badge oh-badge--sheet">키워드만</span> |

!!! tip "정리하면"
    [얕은 잠](shallow-sleep.md) · [깊은 잠](deep-sleep.md)에서 현실 조각을 **모으고**, [영면자](kin.md)에서 현실 조각을 **써서** 키워드 모듈 상자를 받습니다.
