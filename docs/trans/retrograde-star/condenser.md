# 응축기 <small>(솔축기)</small>

!!! abstract "한눈에 보기"
    **중력 응축기**를 설치하면 페이즈별 보스가 차례로 나오는 콘텐츠입니다. **솔축기**는 응축기 솔플을 뜻합니다.
    주간 보상은 5회이고, 레전드 상자를 노리는 사람들이 많이 돕니다.

!!! warning "작성 기준"
    S4 **중력의 심연** 시즌 커뮤니티 글을 바탕으로 정리했습니다. 패치로 수치나 동작이 달라졌을 수 있습니다.

[:material-google-spreadsheet: 응축기 세팅 시트 열기](https://docs.google.com/spreadsheets/d/1UEGz2lsRZplKnUekpb7x1KbgcoPnfPaIQxWSmx4_WMc/edit?gid=802382803#gid=802382803){ .md-button .md-button--primary target="_blank" }

## 기본 정보

| 항목 | 내용 |
|------|------|
| 보스 출현 | 페이즈마다 1분 30초 간격 |
| 최대 시간 | 10분 |
| 설치 제한 | 반경 90m 안에 중복 설치 불가 |
| 주간 보상 | 5회 |

## 모듈

**속(속도), 방(방어), 실** 3개 조합이 추천됩니다.

!!! tip "방어 모듈"
    설명에는 받는 피해 20% 감소라고 되어 있지만, 실제로 테스트해 보면 약 60% 감소 효과가 나왔다는 후기가 있습니다.

## 회복

- **추분** 또는 감염물 **젤**로 회복합니다.
- 서브 무기로 추분 M4를 들면 응축기를 회복시킬 수 있어 혼자서도 안정적입니다.

## 솔축기 세팅 예시

| 무기 | 출처 |
|------|------|
| G17 - 위험물 | 균열자·응축기 솔플 클립 글 (약 4분 클리어) |
| SN700 - 절향 | 중력 응축기 SN700-절향 가이드 |
| AK + 저주인형 → 마지막 보스만 절향 | 질문 글 (탄 소모가 크고 나비 쿨이 답답하다는 후기) |
