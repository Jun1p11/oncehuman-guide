# 중결런

!!! abstract "한눈에 보기"
    **중력 결정 파밍 런**입니다. 정해진 시간 동안 마을을 돌며 별의 보물 상자를 열고 엘리트를 잡아 중력 결정을 모읍니다.

!!! warning "작성 기준"
    2025년 S1 역행하는 별 시즌 커뮤니티 글을 바탕으로 정리했습니다. 시간대나 상자 위치는 패치로 달라졌을 수 있습니다.

## 기본 정보

| 항목 | 내용 |
|------|------|
| 진행 시간 | 인게임 09:00 AM ~ 09:00 PM |
| 현실 시간 | 매시 22분 ~ 52분 (30분) |
| 방식 | 팀 또는 솔플로 상자런 |

## 파밍 3요소

| 대상 | 얻는 것 |
|------|---------|
| :material-treasure-chest: 별의 보물 상자 | 중력 결정, 제조법, 가죽, 감염물(확률) |
| :material-skull: 엘리트 | 감염물(확률) |
| :material-orbit: 불안정 집합체(구체) | 모듈 |

## 상자 위치

- 상자는 보통 **마을마다 1~2개**씩 있습니다.
- 예외로 **상록수 포도원**에는 4개가 있습니다.
